I built this project with HTLM,CSS and JS(the librairy used is p5.js).I started by watching the video "Coding Challenge 21:Mandelbrot set" made by The Coding Train on youtube and then I add my own features and gave it a better style.My limit of click was 48-49(it correspond of a x562949953421312)before getting 
a pixelated image, it's the limit of JS but I could use a librairy like decimal.js to go on higher zoom but the rendering of the image would be much slower(and with my old packard bell laptop with 4gb ram and an intel celeron 4500 it would be worse and very difficult to use my own website).

So to zoom in the fractal just click anywhere on it(warning, the zoom isn't very precise, it is not always centered where you have clicked), the number of times you clicked on it and the actual zoom is above the fractal and you can click on "reset zoom" at any moment to set the zoom to 1, enjoy :).
